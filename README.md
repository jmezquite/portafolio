# Portafolio personal

Primer proyecto del portafolio, creado inicialmente con HTML, CSS y JavaScript
puros.

## Ver el proyecto

Abre `index.html` directamente en el navegador o utiliza una extensión de
servidor local en VS Code.

## Estructura

- `index.html`: contenido y estructura semántica.
- `styles.css`: diseño y adaptación a pantallas pequeñas.
- `script.js`: menú móvil y año del pie de página.

## Siguiente etapa

Sustituir el contenido de ejemplo con datos reales y revisar la página en
diferentes tamaños de pantalla.
